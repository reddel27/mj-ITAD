# mj-ITAD

Inspired by [isthereanydeal.com](https://isthereanydeal.com/), this project aims to create a database for viewing marijuana prices from dispensaries near the user.

## Project Goal

The application will integrate with Google Maps to locate dispensaries near the user's location, scrape their online menus for products and prices, and organize this data into a searchable, filterable database.

## Features

- Location-based search: Use Google Maps API to find nearby dispensaries
- Menu scraping: Automatically collect product information and prices from dispensary websites
- Database storage: Store and organize product data
- Filtering and sorting: Allow users to search, filter, and sort products by price, strain, type, etc.
- User interface: Web-based interface for easy browsing

## Legal and Ethical Considerations

- Ensure compliance with local laws regarding marijuana data
- Respect website terms of service when scraping
- Only collect publicly available pricing information
- Consider API alternatives to scraping where possible

Not at all affiliated with isthereanydeal, totally independent student project.
